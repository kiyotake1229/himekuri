# 許可のダイアログなどを日本語で出す（じぶん日めくり）

- 管理番号: #0008
- 種類: FIX（軽微な修正）
- 対象: iOSアプリ（IOS）
- 作成日: 2026-11-06
- 関連: #0006（プライバシーマニフェスト・ビルド確認）

## 概要

iOS アプリの言語の設定が英語（`CFBundleDevelopmentRegion = en`。`npx cap add ios` で作ったときのまま）だった。そのため日本語の iPhone でも、通知や写真の許可を求めるダイアログ、共有シートなど、iOS が出す文言が英語で出るおそれがあった。設定を日本語（`ja`）にし、対応言語も日本語（`CFBundleLocalizations = [ja]`）と書いた。そなえ帳・思考力と同じ設定。

## 対象ファイル

- `ios-app/ios/App/App/Info.plist`
- `.github/workflows/ios-build.yml`（言語の設定の確認を追加）

## 変更内容

- `CFBundleDevelopmentRegion`: `en` → `ja`
- `CFBundleLocalizations`: `ja` だけの一覧を足した
- 変わるのは、iOS が出す文言（許可のダイアログのボタン、共有シートなど）と、App Store に表示される対応言語。アプリの画面（Web の部分）は日本語で書いてあり、日付や曜日も自前で組み立てているので変わらない。ウィジェット拡張（`ios/App/Widget/Info.plist`）はもともと `ja_JP` なので変えていない
- ビルド確認: できたアプリの `Info.plist` で `CFBundleDevelopmentRegion` が `ja`、`CFBundleLocalizations` に `ja` があることを確かめる。iOS のプロジェクトを作り直したときなどに、英語へ戻るのを防ぐ
