## 概要

自分で作る日めくりカレンダー。言葉や写真を「カード」にしておくと、毎日1枚が決まって出る。1日1行の「ひとこと」を書くと、来週・来月・来年の同じ日に戻ってくる。Web版（単一HTML・PWA）は完成し、ブラウザで動作確認済み。iOS版は Capacitor 7 のプロジェクトに WidgetKit 拡張（ホーム画面・ロック画面ウィジェット）を Swift で組み込んだ状態。**Xcode でのビルド確認は未実施**（この Mac に Xcode が無い。GitHub に push して macOS ランナーで確認する予定）。2026-10-27 に docs 管理を始めた時点の内容。以後の変更は #0002 以降の文書に記録する。

## 仕様

### 画面と機能

**共通**

- 下のタブは「今日 / カード / きろく / 設定」の4つ。画面は `#s-today` `#s-cards` `#s-log` `#s-set`
- ヘッダー右のボタン（`#redrawBtn`）は「もう1枚めくる」。今日タブだけに出て、カードが2枚未満なら押せない
- 初回起動時はようこそ画面（`#welcome`）。「見本のカードを入れる」（初期ON）で `SAMPLES` 13枚を入れる。カードが0枚のまま始めるとカードタブに移る
- 日付が変わると「前の日の紙が破れて今日の紙が出る」演出（`openDayFlow()`）。30秒ごとと画面復帰時に `tick()` が確認する

**今日タブ（`#s-today`）**

- 紙の台（`#pad`）に、今日の紙（`#sheet`）と前の日の紙（`#sheetOld`、演出時だけ）と奥の紙2枚（`.ghost`）
- 紙の中身（`sheetHTML()`）: 綴じ部（穴2つ）、年月、日の数字、曜日、差し色の線、本文（写真 / 言葉 / 出典）、下段に「今年N日目 / あとN日」
- 言葉の大きさは文字数で変わる（14字以下 `len-s`、51〜120字 `len-l`、121字以上 `len-xl`）。縦書き設定なら `vert`。写真があれば `with-photo`
- 紙を上に引く（`pointerdown` → 90px以上上へ）か右上ボタンで「もう1枚」（`redraw()`）。全カードから今とは別の1枚を無作為に選び、`overrides[今日]` に記録する。紙が破れる演出と音・振動
- 引っぱりのヒント（`#pullHint`）は5回めくるまで出す（`meta.hintShown`）
- ひとこと欄（`#noteInput`、100字）。Enter か右のチェックで保存。空にすると消える
- 「この日のひとこと」（`renderMemories()`）: 去年の今日 → N年前の今日（10年まで）→ 先月の今日 → 先週の今日 → きのう、のうち書いてあるものを横並びに出す。タップで日のシートを開く。何も無ければ案内文

**カードタブ（`#s-cards`）**

- 新しい順に並ぶ。サムネイル（写真か先頭1文字）、本文2行、チップ（記念日 M/D・曜日・写真・出典）
- 「追加」で編集シート（`#cardModal`）: 本文（300字）、写真（端末の画像を選ぶ。長辺1000px・JPEG 0.8 に縮小）、出典・メモ（40字）、いつ出す（いつでも / 記念日 月日 / 曜日 複数可）、編集時は削除
- 「まとめて」（`#bulkModal`）: 1行＝1枚で追加
- 0枚のときは案内と「カードを書く」「見本を入れる」

**きろくタブ（`#s-log`）**

- 数字3つ: 書いた日（ひとことの数）、連続（今日からさかのぼって続けて書いた日数。今日未記入なら昨日から数える）、めくった日（`shown` の数）
- 月カレンダー（`#calGrid`）。ひとことのある日は濃い点、めくっただけの日は薄い点。未来の日は押せない。日をタップで日のシート（`#dayModal`）: その日に出たカードと、ひとことの追記・修正
- 最近のひとこと12件

**設定タブ（`#s-set`）**

- 紙: 白紙 `white` / 和紙 `washi` / クラフト `kraft` / 空 `sora` / 桜 `sakura` / 墨 `sumi`（`PAPERS`、`[data-paper]` の CSS 変数）
- 差し色: 朱 `shu` / 藍 `ai` / 松 `matsu` / 金茶 `kincha` / 藤 `fuji` / 墨 `sumi`（`ACCENTS`）
- 文字: ゴシック / 明朝 / 丸ゴシック（`--font-sheet`。端末のフォント）、大きさ 小・中・大（`--fs`）、縦書き
- めくり方: 出す順（おまかせ `random` / 順番 `order`）、紙の音、振動
- 朝の通知: ON/OFF と時刻（iOS版のみ届く。Web版は案内）
- ウィジェット: 置き方の案内（iOS版）
- 画面の明るさ: 明るい / 暗い / 自動（紙の色は別。UI の色だけ変わる）
- データ: バックアップを保存（`himekuri-backup-YYYY-MM-DD.json`。共有シートが使えればそれ、無ければダウンロード）、復元（置き換え）、見本の再投入、すべて消す

### その日のカードの決め方（`poolFor()` `baseIndex()` `basePick()` `pickFor()`。Swift の `HK` も同じ）

1. `overrides[日付]` があればそのカード（手動で「もう1枚」した日）
2. 候補: 記念日カードでその月日のもの → 無ければ曜日カードでその曜日のもの → 無ければ「いつでも」のカード → それも無ければ全カード。`order` 昇順・`id` 順に並べる
3. 番号: おまかせは FNV-1a ハッシュ（`seed + '|' + 'YYYY-MM-DD'`）を候補数で割った余り。順番は 1970-01-01 からの日数を候補数で割った余り
4. 候補が2枚以上で、前日の（手動を除く）カードと同じなら1つ後ろにずらす
- 日付の計算は `daysFromCivil()`（時差に影響されない整数計算）。曜日もそこから出す。JS と Swift で同じ式にしてある

### データの保存

- 保存先は localStorage。キーは `himekuri.v1`（定数 `KEY`）。状態全体を JSON 文字列で1件に保存する
- 写真は IndexedDB（DB `himekuri`、ストア `img`、キーはカードID、値は data URI）。IndexedDB が使えなければ localStorage の `himekuri.img`
- iOS版は同じ JSON を Capacitor Preferences にも書く（`save()`）。起動時に `hydrateFromNative()` が読み、カード＋ひとことの数が多ければ置き換える
- iOS版はさらに `syncWidget()` が App Group の `himekuri.json` に書く（カード本文・出典・種類・日付・曜日・順番・写真の有無、ひとこと、手動めくりの記録、設定の一部）。写真は `putImage()` で長辺600pxに縮小して `img_<ID>.jpg`。初回は全写真を送る（`meta.widgetFull`）

**状態（`state`）の中身**

| キー | 内容 |
|------|------|
| `cards` | カードの配列（下表） |
| `notes` | ひとこと `{"YYYY-MM-DD": "本文"}` |
| `shown` | その日に出たカード `{"YYYY-MM-DD": カードID}` |
| `overrides` | 手動でめくり直した日 `{"YYYY-MM-DD": カードID}` |
| `settings` | `paper` `font` `size` `accent` `vert` `mode` `sound` `haptic` `theme` `notify` `notifyTime` `seed`（乱数の種。初回に8文字） |
| `meta` | `lastOpenDate`（最後に開いた日。演出の判定）`onboarded` `seeded` `createdAt` `hintShown` `widgetFull` |

**`cards` の1件**

| キー | 内容 |
|------|------|
| `id` | `"c" + 時刻(36進) + 乱数` |
| `text` / `sub` | 本文・出典 |
| `kind` | `"any"` / `"date"` / `"wday"` |
| `date` | `"MM-DD"`（記念日） |
| `wdays` | 曜日番号の配列（0=日） |
| `order` | 作成順の整数（選ぶときの並び） |
| `createdAt` | 作成時刻 |
| `img` | 写真があるか |

### 通知・触覚・音

- 通知（iOS版、`scheduleNotifications()`）: 設定の時刻に、今日から7日分（ID 3001〜3007）を予約。本文はその日のカードの言葉（80字まで）。設定変更・画面復帰で予約し直す
- 触覚（`haptic()`）: iOS版は Capacitor Haptics、Web版は `navigator.vibrate`
- 音（`playTear()` `playTick()`）: WebAudio でその場で作る（ノイズ＋バンドパスで紙の音、正弦波で保存音）。音源ファイルは無い

### ウィジェット（iOS版、`ios-app/ios/App/Widget/`）

- `TodayCardWidget`（kind `TodayCard`、表示名「今日の1枚」）: ホーム画面 小・中・大、ロック画面 長方形・1行・丸。紙の色・差し色・書体の設定を反映。写真カードは写真を背景に日付と言葉を白で重ねる。タップで `himekuri://today`
- `MemoryWidget`（kind `Memory`、表示名「この日のひとこと」）: ホーム画面 小、ロック画面 長方形・1行。去年の今日などのひとこと
- タイムライン: 今と、以後3日分の0時にエントリを作り `.atEnd` で更新。アプリ側の `setData` のたびに `reloadAllTimelines()`
- iOS 17 以降は `containerBackground`、16 は `background` に切り替える（`widgetBackground()`）
