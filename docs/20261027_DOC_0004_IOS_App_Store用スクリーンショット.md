# App Store 用スクリーンショット

- 管理番号: #0004
- 種類: DOC（ドキュメント作成）
- 対象: iOSアプリ（IOS）
- 作成日: 2026-10-27
- 関連: #0001、#0003

## 概要

App Store Connect に載せるスクリーンショットを、見出し入りで 6場面 × 4サイズ（iPhone 6.9 / 6.7 / 6.5 / 5.5インチ）作った。暗転・凪の池と同じ仕組み（Node.js から Chrome を画面なしで動かし、台紙 HTML の中でアプリに保存データを仕込んで撮る）。あわせて、縦書きの本文が紙の上に寄っていたのを中央に直した（軽微な修正）。

## 対象ファイル

- `tools/make-screenshots.mjs` — 撮影スクリプト（新規）。小さな Web サーバを立て、Chrome を `--headless=new` で起動し、DevTools Protocol で端末サイズを指定して撮る
- `tools/screenshot-frame.html` — 台紙（新規）。見出し・副題・端末枠の中の `iframe` で `../index.html` を開く。場面ごとの保存データ（`seedState()`）と写真（`makePhoto()`、Canvas で描く夕焼け）を仕込む
- `ios-app/screenshots/<端末>/<番号>-<場面>.jpg` — 出力（24枚、約4MB）
- `index.html` — `.sheet-text.vert` の `height:100%` を `auto` に（縦書きの本文を紙の中央に置く）
- `ios-app/ios/App/App/public/index.html` — 上の変更を同梱分にも反映
- `README.md` / `ios-app/README.md` / `ios-app/岩崎さんへの引き渡し手順.md` / `../README.md` — スクリーンショットの案内

## 変更内容

### 1. 場面（6つ。番号順にアップロードする）

| 番号 | 場面 | 見出し | 中身 |
|---|---|---|---|
| 1 | today | 毎朝、1枚めくれる | 白紙・朱。言葉のカードと「紙を上に引っぱると」の案内 |
| 2 | photo | 写真も、1枚のカードに | 空の紙・藍。夕焼けの写真カード |
| 3 | memories | 1行だけ、書く | 和紙・松・明朝。今日のひとことと「去年の今日」「先月の今日」 |
| 4 | cards | カードは、自分で作る | カード一覧（写真・記念日・曜日・出典のチップ） |
| 5 | log | 積もっていく、ひとこと | きろく（数字3つ・カレンダー・最近のひとこと） |
| 6 | night | 紙も文字も、自分好みに | 墨・金茶・明朝・縦書き・暗い画面 |

### 2. サイズ

| フォルダ | CSS ピクセル | 倍率 | 画像 | 備考 |
|---|---|---|---|---|
| `iphone-6.9` | 440×956 | 3 | 1320×2868 | App Store Connect の必須枠 |
| `iphone-6.7` | 430×932 | 3 | 1290×2796 | |
| `iphone-6.5` | 414×896 | 3 | 1242×2688 | 6.9 の代わりにも使える |
| `iphone-5.5` | 414×736 | 3 | 1242×2208 | |

アプリの表示領域は、ステータスバーとホームバーの分を引いた大きさ（`iw` / `ih`）にしている。

### 3. 撮り方の要点

- 台紙が `localStorage` の `himekuri.v1` に場面ごとの状態を書いてから `iframe` を読み込む。写真は読み込み後に `putImage()` で IndexedDB に入れる
- 初回案内は済み（`onboarded`）、`lastOpenDate` は今日（破れる演出を出さない）、音と振動は OFF
- 撮る直前に `animation` と `transition` を止め、トーストを消す
- 思い出の無い場面（1・2・6）は、下の「この日のひとこと」を隠して画面下の見切れを無くす。3 は紙を少し低くして思い出の列を見せる
- 作り直すとき: `node tools/make-screenshots.mjs`（Node.js 22 以降と Google Chrome が必要。日付は実行日のものが入る）

### 4. 縦書きの位置（軽微な修正）

`.sheet-text.vert` が `height:100%` で紙の本文領域いっぱいに伸び、文字が上に寄って見えていた。`height:auto` にして、各行は天付きのまま、ブロック全体を紙の中央に置くようにした。
