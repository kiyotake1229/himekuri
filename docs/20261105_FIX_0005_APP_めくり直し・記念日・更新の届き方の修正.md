## 変更内容

### 1. 「もう1枚」は今日に合うカードから選ぶ（`fitsToday()` `redraw()`）

これまでは全カードから選んでいたため、別の日の記念日カードや別の曜日のカードが出ることがあった。「いつでも」「今日の曜日」「今日の記念日」に絞り、それで候補が無いときだけ全カードに戻す。

### 2. 記念日の日を月に合わせて絞る（`buildDayOptions()`）

日の選択肢が常に1〜31だったので「2月30日」が作れ、そのカードは一度も出なかった。月を変えると日の選択肢を 29 / 30 / 31 に作り直し、選んでいた日が超えていれば末日に寄せる。2月はうるう年の29日まで。

### 3. Service Worker を「本体はネット優先」に（`sw.js`）

キャッシュ優先だったので、Pages の `index.html` を直しても、ホーム画面に追加した人には `sw.js` のキャッシュ名を上げるまで古いままだった。`index.html`（と `/`、ページ遷移）はネットを先に取り、だめならキャッシュ。アイコンなどはキャッシュ優先のまま。キャッシュ名を `himekuri-v2` にして、既存の利用者の古いキャッシュを捨てる。

### 4. ウィジェットへの初回送信は成功したときだけ「済み」に（`syncWidget()`）

`setData` や `saveImage` が失敗しても `meta.widgetFull` を立てていたので、App Group が一時的に使えない起動が1回あると、既存の写真がウィジェットに届かないままになっていた。すべて成功したときだけ立てる。

### 5. 今日の画面で紙を少し低く（`.pad`）

紙は「上に引くとめくる」ために指のスクロールを受け付けない。62vh では小さい iPhone でひとこと欄や「この日のひとこと」が下に隠れていた。56vh（最大500px、最小360px）にして、ひとこと欄と思い出の見出しが最初から見えるようにした。375×812 で紙の下端 529px、ひとこと欄 621px、思い出の見出し 693px（タブバーは 726px から）。

### 6. Actions を md とスクリーンショットでは走らせない

`ios-app/` の中の `.md` と `screenshots/` の変更を `paths` から除外した。

### 7. 「順番」モードの説明を追加

カードを足したり消したりすると並びが変わる仕組みなので、設定の説明にその旨を書いた。

## 確認したこと（Claude の Browser、375×812、音はミュート）

- 別の日の記念日カードと別の曜日のカードを混ぜて「もう1枚」を50回 → それらは一度も出ず、「いつでも」3枚と今日の曜日カードだけが出た
- 記念日の日の選択肢: 2月 29 / 4月 30（29日を選んでいたら29のまま）/ 1月 31
- 紙・ひとこと欄・思い出の見出しの位置（上記）
- 設定の説明文が出ている。Service Worker が `himekuri-v2` で有効
- push 後に GitHub Actions の iOS ビルドが通り、Pages に反映されたこと
