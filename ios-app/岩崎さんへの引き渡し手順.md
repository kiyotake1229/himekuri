# 岩崎さんへ — 「じぶん日めくり」iOSアプリ ビルド・申請手順

岩崎さん

自分で作る日めくりカレンダー「じぶん日めくり」のiOSプロジェクトです。
今回は、これまでのアプリと違い **ホーム画面・ロック画面のウィジェット**（Swift）が付いています。

ビルドが通ることは GitHub の自動ビルド（Xcode 26.6、署名なし）で確認済みです。シミュレータ向け・実機向けの両方が通り、ウィジェット拡張がアプリに組み込まれることまで確かめてあります。
署名を付けた実機での確認はまだなので、3章の手順で開いてエラーが出たら清武までお知らせください。

必要な作業は大きく2つです。

1. Xcodeで開いて、署名（Team）を自社アカウントに設定してビルド → 3章
2. App Store Connect にアップロードして審査に提出 → 4章

申請時に入力するアプリ名・説明文・キーワードなどは、4章に**下書きを用意してあります**。
そのまま使っていただいても、修正いただいても構いません。

## 1. アプリ概要

| 項目 | 内容 |
|------|------|
| アプリ名 | じぶん日めくり |
| Bundle ID | `work.ltv.himekuri`（ウィジェット: `work.ltv.himekuri.widget`） |

## 3. ビルド手順

このフォルダ（`ios-app/`）で、以下を順に実行してください。

```bash
# 1) 依存パッケージを取得
npm install

# 2) Webアプリを同梱し、CocoaPods を入れる（初回は数分かかります）
npm run sync

# 3) アイコンと起動画面を生成する（初回のみ）
npm run icons

# 4) Xcodeで開く
open ios/App/App.xcworkspace
```

> **注意**: 必ず `App.xcworkspace` を開いてください（`App.xcodeproj` ではありません）。
> `App.xcworkspace` は 2) の `npm run sync` で CocoaPods が作ります。

### Xcode上での設定

1. 左ペインで **App** を選択 → **Signing & Capabilities** タブ
2. **Team** に自社のApple Developerアカウントを選択（"Automatically manage signing" はON）
3. 同じ画面で **HimekuriWidget** ターゲットも選び、同じ Team を設定する（ターゲットは画面上部の一覧で切り替えられます）
4. 両方のターゲットに **App Groups**（`group.work.ltv.himekuri`）が付いています。Team を設定すると Xcode が自動で登録します。赤い警告が出る場合は、App Groups の横の更新ボタンを押してください
5. Bundle Identifier を自社のものに変えたい場合は、`work.ltv.himekuri` → 自社ID、`work.ltv.himekuri.widget` → 自社ID + `.widget` のように**2つとも**変えてください。App Group の名前（`group.work.ltv.himekuri`）は `ios/App/App/App.entitlements`・`ios/App/Widget/Widget.entitlements`・`ios/App/App/WidgetBridgePlugin.swift`・`ios/App/Widget/HimekuriData.swift` の4か所にあります。変える場合は4か所とも同じ名前にしてください
6. **General** タブで **Version**（例: 1.0.0）と **Build**（例: 1）を設定（App と HimekuriWidget は同じ値にする）

### 動作確認

- 上部のデバイス選択から実機またはシミュレータを選び、スキームは **App** のまま ▶ で起動
- ウィジェットの確認: ホーム画面を長押し → 左上の「＋」→「じぶん日めくり」を選んで追加。ロック画面は、ロック画面を長押し → カスタマイズ → ウィジェットを追加
- アプリでカードを作ると、ウィジェットが数秒で更新されます

## 4. App Store申請

1. Xcode: **Product → Archive**
2. Organizerが開いたら **Distribute App → App Store Connect** でアップロード
3. [App Store Connect](https://appstoreconnect.apple.com) でアプリ情報を入力して審査提出

### 申請情報（下書き）

**アプリ名**
```
じぶん日めくり - 自分で作る日めくり
```

**サブタイトル（30字以内）**
```
好きな言葉と写真が、毎朝1枚めくれる。
```

**説明文**
```
「じぶん日めくり」は、自分で作る日めくりカレンダーです。
好きな言葉、家族の写真、今年の目標、覚えたい言葉。なんでもカードにしておくと、毎朝1枚がめくれて出てきます。

■ カードは自分で作る
言葉でも写真でも1枚に。「記念日に必ず出す」「毎週月曜に出す」といった決め方もできます。まとめて貼り付けて一気に作ることもできます。

■ 毎朝1枚、紙がめくれる
日付が変わって開くと、前の日の紙が破れて今日の1枚が現れます。紙を上に引けば、もう1枚。

■ 1行だけ書く
その日のひとことを1行だけ。書いた1行は、来週・来月・来年の同じ日に「去年の今日」として戻ってきます。続けるほど、懐かしさが積もります。

■ ホーム画面とロック画面に
ウィジェットを置けば、アプリを開かなくても今日の1枚が目に入ります。ロック画面には「去年の今日」のひとことも。

■ 紙も文字も、自分好みに
紙は白紙・和紙・クラフト・空・桜・墨の6種類。差し色6色。ゴシック・明朝・丸ゴシック、縦書きにも対応。

■ 朝の通知
決めた時刻に、その日のカードの言葉が通知で届きます。

■ その他
・きろく画面で、書いた日・連続日数・カレンダーを振り返れる
・バックアップの保存と復元（写真込み）
・ダークモード対応
・完全オフライン動作。データは端末内にのみ保存され、外部に送信されません。
```

**キーワード（100字以内・カンマ区切り）**
```
日めくり,カレンダー,名言,日記,一行日記,ひとこと,ウィジェット,ロック画面,写真,言葉,習慣,手帳,思い出
```

- プライマリ: ライフスタイル
- セカンダリ: 仕事効率化

**年齢制限**: 4+

### プライバシー情報（App Store Connect「App のプライバシー」）

- **データを収集しません** を選択してください。
- 理由: 本アプリは通信機能を持たず、すべてのデータは端末内（localStorage / IndexedDB / App Group の共有フォルダ）にのみ保存されます。アナリティクス・広告・トラッキングは一切ありません。

## 5. 審査で見られやすい点

Appleガイドライン **4.2（最低限の機能）** について、本アプリは以下を満たしています。申請時の備考欄に記載すると安全です。

- 完全オフラインで動作する自立したアプリ（Webサイトの単なる表示ではない）
- 端末内にデータを保存し、継続的に利用する設計（毎日のカードとひとこと）
- ネイティブのウィジェット（ホーム画面・ロック画面）、ローカル通知、触覚フィードバックを実装

## 6. アプリ内容を修正したい場合

アプリ本体は 1つ上のフォルダの `index.html` です。修正後、このフォルダで：

```bash
npm run sync
```

を実行するとiOSプロジェクトに反映されます。その後Xcodeで再ビルドしてください。
ウィジェットの見た目を変えたい場合は `ios/App/Widget/HimekuriWidget.swift` です。
